# Bolt Auth Clone

A responsive, Bolt-inspired authentication interface.

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.

## Features

- Sign-up and sign-in flows
- Client-side user storage
- Form validation
- Password reset request UI
- Light/dark themes
- Responsive mobile and desktop layouts

## OAuth setup

Google and GitHub buttons are prepared for OAuth integration. Live provider authentication requires provider credentials and a secure backend callback.
